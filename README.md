# 🔔 Discord Deadline Manager & Roast Bot

บอท Discord สำหรับช่วยบริหารจัดการงาน กำหนดวันส่ง (Deadline) พร้อมระบบแจ้งเตือนด้วยภาพนับถอยหลัง (Countdown) และคลังคำด่า/ข้อความกวนๆ สำหรับสุ่มเตือนสติสมาชิกใน Server

---

## 🌟 คุณสมบัติหลัก (Features)

* **⏳ Deadline Notifications**: เลือกรูปภาพ กำหนดวัน-เวลา และความถี่ในการแจ้งเตือน ระบบจะสร้างรูปภาพนับถอยหลัง (Countdown) สรุปเวลาที่เหลือให้อัตโนมัติ
* **🖼️ Interactive Album Management**: ระบบ GUI (Select Menu & Buttons) สำหรับจัดการรูปภาพในอัลบั้ม สามารถดูรูป เปลี่ยนชื่อ หรือลบไฟล์ภาพผ่าน Discord ได้โดยตรง
* **🔥 Roast System**: คลังคำด่า/คำเตือนสติ สุ่มส่งข้อความเมื่อมีคนแท็กหาบอท หรือสุ่มตอบกลับในแชท สามารถเพิ่ม/แก้ไข/ลบรายการคำด่าผ่าน Slash Commands ได้ทันที
* **🌐 Global Slash Commands**: รองรับการใช้งาน Slash Commands (`/`) ในทุก Server ที่บอทเข้าร่วม

## 🧠 หลักการทำงานของโปรเจกต์ (Architecture & Workflow)

การทำงานของระบบแบ่งออกเป็น 4 ส่วนหลัก ดังนี้:

### 1. การจัดการคำสั่งและการซิงก์ (Command Handling & Global Sync)
* บอทใช้ **`discord.app_commands` (Slash Commands)** เพื่อสร้าง UI การตอบสนองที่ทันสมัย
* ในขั้นตอนการเปิดบอท (`setup_hook`) ระบบจะเรียกใช้ `await self.tree.sync()` เพื่อลงทะเบียนคำสั่ง Slash Commands ทั้งหมดแบบ Global ไปยัง Discord API 

### 2. ระบบประมวลผลรูปภาพนับถอยหลัง (Dynamic Countdown Image Generation)
* เมื่อถือกำหนดเวลาตามรอบการแจ้งเตือน ระบบจะดึงรูปภาพที่ผู้ใช้เลือก (หรือสุ่มเลือก) จากโฟลเดอร์ `album/`
* ใช้ไลบรารี **Pillow (PIL)** ในการโหลดและวาดข้อความเวลาที่เหลืออยู่ (เช่น `2d 4h 15m`) ลงบนรูปภาพแบบเรียลไทม์ พร้อมใส่เงาเพื่อเพิ่มความชัดเจนของข้อความ
* แปลงไฟล์ภาพผลลัพธ์ผ่าน Memory Buffer (`io.BytesIO`) แล้วส่งเข้าไปในช่องแชท Discord ทันทีโดยไม่ต้องบันทึกไฟล์ภาพชั่วคราวลงดิสก์

### 3. ระบบลูปแจ้งเตือนเบื้องหลัง (Background Task Loop)
* บอททำงานร่วมกับ **`discord.ext.tasks`** โดยรันลูปตรวจสอบ (`@tasks.loop(minutes=1)`) ทุกๆ 1 นาที
* ลูปจะทำการเปรียบเทียบเวลาปัจจุบัน (`datetime.now()`) กับเวลา Deadline และรอบความถี่ (`interval_minutes`) ที่บันทึกไว้ในหน่วยความจำ (`active_tasks`)
* หากถึงรอบการเตือน ระบบจะสร้างและส่งภาพ Countdown เข้าสู่ช่องแชท และหากเวลาเหลือน้อยกว่าหรือเท่ากับ 0 ระบบจะแจ้งเตือนสิ้นสุดงานและลบ Task ออกอัตโนมัติ

### 4. ระบบจัดการข้อมูลและการโต้ตอบ (Data Persistence & Interactive UI)
* **คลังคำด่า (Roast Data):** บันทึกและดึงข้อมูลข้อความกวนๆ ผ่านไฟล์ `roast_list.json` ทำให้ข้อมูลไม่หายเมื่อปิดบอท
* **การตอบสนองอัตโนมัติ:** เมื่อมีข้อความส่งเข้ามาใน Server บอทจะตรวจจับผ่าน Event `on_message` หากถูก Mention หรือผ่านเงื่อนไขการสุ่ม (30%) บอทจะดึงคำด่าจากคลังขึ้นมาสุ่มตอบกลับ
* **Discord Components View & Modal:** ระบบ GUI สำหรับจัดการอัลบั้มรูปภาพและตั้งเวลางาน ใช้ประโยชน์จาก `discord.ui.Select`, `discord.ui.Button` และ `discord.ui.Modal` เพื่อให้ผู้ใช้กรอกข้อมูลผ่าน Form ได้โดยง่าย
