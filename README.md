# 🔔 Discord Deadline Manager & Roast Bot

บอท Discord สำหรับช่วยบริหารจัดการงาน กำหนดวันส่ง (Deadline) พร้อมระบบแจ้งเตือนด้วยภาพนับถอยหลัง (Countdown) และคลังคำด่า/ข้อความกวนๆ สำหรับสุ่มเตือนสติสมาชิกใน Server

---

## 🌟 คุณสมบัติหลัก (Features)

* **⏳ Deadline Notifications**: เลือกรูปภาพ กำหนดวัน-เวลา และความถี่ในการแจ้งเตือน ระบบจะสร้างรูปภาพนับถอยหลัง (Countdown) สรุปเวลาที่เหลือให้อัตโนมัติ
* **🖼️ Interactive Album Management**: ระบบ GUI (Select Menu & Buttons) สำหรับจัดการรูปภาพในอัลบั้ม สามารถดูรูป เปลี่ยนชื่อ หรือลบไฟล์ภาพผ่าน Discord ได้โดยตรง
* **🔥 Roast System**: คลังคำด่า/คำเตือนสติ สุ่มส่งข้อความเมื่อมีคนแท็กหาบอท หรือสุ่มตอบกลับในแชท สามารถเพิ่ม/แก้ไข/ลบรายการคำด่าผ่าน Slash Commands ได้ทันที
* **🌐 Global Slash Commands**: รองรับการใช้งาน Slash Commands (`/`) ในทุก Server ที่บอทเข้าร่วม

---

## 🛠️ คำสั่งที่ใช้งานได้ (Commands)

### ⏳ ระบบแจ้งเตือน & อัลบั้ม
| คำสั่ง | รายละเอียด |
| :--- | :--- |
| `/task` | เริ่มต้นตั้งค่าการแจ้งเตือนงาน (เลือกระบบสุ่มรูปภาพ หรือรูปภาพเฉพาะ พร้อมเลือกวันเวลาด่วน/กำหนดเอง) |
| `/add_photo` | อัปโหลดรูปภาพใหม่เข้าอัลบั้มเพื่อนำไปใช้งาน |
| `/manage_album` | เปิดหน้าต่าง GUI จัดการรูปภาพ (เปลี่ยนชื่อไฟล์ / ลบรูปภาพ) |
| `/help` | แสดงคำแนะนำการใช้งานและรายการคำสั่งทั้งหมด |

### 🔥 ระบบจัดการคลังคำด่า
| คำสั่ง | รายละเอียด |
| :--- | :--- |
| `/add_roast [ข้อความ]` | เพิ่มคำใหม่เข้าคลัง (ใช้ `/` แยกเพิ่มหลายคำพร้อมกันได้ เช่น `พิมพ์งานยัง/ตั้งใจหน่อย`) |
| `/list_roast` | ดูรายการคำด่าทั้งหมดในคลังพร้อมหมายเลขอ้างอิง |
| `/edit_roast [ลำดับ] [ข้อความใหม่]` | แก้ไขข้อความในคลังตามลำดับเลข |
| `/delete_roast [ลำดับ]` | ลบข้อความออกจากคลังตามลำดับเลข |
